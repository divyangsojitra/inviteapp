# Phase-wise Roadmap

## Phase 0: Foundation

Build the secure and reusable platform foundation.

- Monorepo structure.
- Cloudflare Worker API shell.
- Next.js public invitation shell.
- Flutter app shell.
- PostgreSQL migration strategy.
- Firebase Authentication integration plan.
- Reusable UI tokens and components.
- CI/CD, linting, type checks, test scaffolding.
- Security standards, audit logging, validation, rate limiting, and environment separation.

## MVP: Invite, Share, RSVP, Remind

Validate the core user journey:

```text
Host creates event -> publishes invite -> shares on WhatsApp -> guest opens web page -> RSVP -> add reminder/calendar
```

MVP scope:

- Event creation.
- English, Hindi, Gujarati.
- Wedding, birthday, Godh Bharai, housewarming, religious event, corporate event, funeral/memorial, custom event.
- Multi-function events.
- Static/basic motion templates.
- Mobile public invitation page.
- WhatsApp sharing, copy link, QR code.
- RSVP without guest login.
- Remind Me and calendar integration.
- Google Maps links.
- Host guest dashboard.
- Basic admin.
- Basic analytics.

## Phase 2: AI, Video, Payments

- Video invitation templates.
- AI invitation text and translation.
- AI video script.
- AI voiceover after quality validation.
- SMS, WhatsApp, and email reminders.
- Custom RSVP questions.
- Food, travel, accommodation fields.
- Co-hosts and polls.
- Razorpay and Stripe.
- Donations, charity, gifting, paid events.
- Premium templates and paid event plans.

## Phase 3: Local Vendor Marketplace

- Vendor registration and approval.
- Vendor categories by event type.
- Location-aware vendor recommendations.
- Vendor leads and quote requests.
- Sponsored placements and vendor subscriptions.

## Phase 4: Full Event Platform

- Gift registry.
- Potluck and what-to-bring lists.
- Seating charts.
- QR check-in.
- Event chat and private messaging.
- Shared gallery.
- AI thank-you cards/videos.
- Event planner and white-label accounts.
