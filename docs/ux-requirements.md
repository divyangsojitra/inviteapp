# UX Requirements

Invieasy must be simple for all generations while still feeling modern.

Core principle:

```text
Simple by default, powerful when needed.
```

## Requirements

- A first-time user should create a basic invitation in under 3 minutes.
- Guest RSVP must not require account creation.
- Public invitation pages must be mobile-first and responsive.
- Essential guest information must appear in the first viewport.
- Main guest actions should be easy to reach: RSVP, Remind Me, Directions.
- All core screens must support English, Hindi, and Gujarati.
- Forms must autosave drafts.
- Inputs must use clear labels, examples, and inline validation.
- Buttons must use plain language.
- Avoid icon-only critical actions.
- Minimum touch target: 44px.
- No horizontal scrolling on mobile.
- Regional text must wrap correctly.
- All screens must use reusable design-system components.

## Public Invite First View

The first view should clearly show:

- Event name
- Host/invite context
- Date and time
- Venue
- RSVP action
- Reminder action
- Directions action

Decorative story, gallery, and extra content can appear below.
