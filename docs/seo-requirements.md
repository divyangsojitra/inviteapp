# SEO Requirements

Public web pages must be mobile-first, responsive, accessible, fast-loading, and SEO-ready.

## Indexing Rules

Indexable:

- marketing pages
- template category pages
- public vendor pages
- public help/blog content

Noindex:

- private family event pages
- guest-specific RSVP URLs
- drafts
- admin pages
- host dashboard pages

## Technical Requirements

- Server-rendered/indexable HTML for public pages.
- Unique title and meta description.
- Canonical URL.
- Open Graph metadata for WhatsApp/social previews.
- Twitter/X card metadata.
- Semantic HTML.
- Sitemap generation.
- `robots.txt`.
- Structured data where relevant:
  - Event
  - Organization
  - LocalBusiness
  - BreadcrumbList
- Multilingual `hreflang` for English, Hindi, and Gujarati pages where indexed.
- Optimized images and lazy loading.
- Strong Core Web Vitals.
